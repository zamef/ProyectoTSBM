\section{Introducción}

El queratocono es una ectasia corneal no inflamatoria que se caracteriza por el adelgazamiento de la córnea y la protrusión de la misma en forma de cono, lo que resulta en astigmatismo, miopía y deterioro de la agudeza visual. Esta condición típicamente aparece durante la pubertad y continúa progresando hasta los 30 - 40 años \cite{rabinowitz, namba, rubido}.

\begin{figure}[hbt!]
    \centering
    \includegraphics[width=0.85\columnwidth]{imagenes/Keratoconus.png}
    \caption{Esquema de queratocono comparado a una córnea normal. \cite{keraimagen}}
    \label{fig:Queratocono}
\end{figure}

La incidencia del queratocono en la población general se estima en aproximadamente 1 por cada 2,000 personas (50-230 por 100,000 habitantes). El queratocono afecta por igual a ambos sexos y se presenta en todos los grupos étnicos, aunque se han reportado mayores prevalencias en poblaciones asiáticas (igualmente puede haber un sesgo debido a la cantidad de estudios realizados). \cite{rabinowitz, namba}

El queratocono se manifiesta dependiendo de la etapa en la que se encuentre.

\begin{itemize}[itemsep=-2pt]
    \item \textbf{Signos tempranos}: Incluyen astigmatismo irregular leve y cambios sutiles en la topografía corneal que pueden pasar desapercibidos en exámenes de la vista comúnes \cite{rabinowitz}.
    \item \textbf{Signos avanzados}: Incluyen adelgazamiento estromal, anillo de Fleischer, estrías de Vogt y signo de Munson (el famoso cono) \cite{rabinowitz}.
\end{itemize}

\subsection{Diagnóstico}

El diagnóstico temprano del queratocono es crucial, especialmente en candidatos a cirugía o en etapas tempranas, para evitar su desarrollo a etapas mas avanzadas. Algunos de los procedimientos utilizados actualmente son los siguientes.

\begin{itemize}[itemsep=-2pt]
    \item \textbf{Examen clínico}: Evaluación de agudeza visual, retinoscopia y biomicroscopía.
    \item \textbf{Topografía corneal}: Es el método más sensible para una detección temprana, mostrando patrones como aumento localizado de la potencia corneal, asimetría infero-superior y desviación de los ejes \cite{rabinowitz}.
    \item \textbf{Tomografía corneal}: Este estudio evalúa tanto las superficies anterior y posterior como el espesor corneal, permitiendo detectar alteraciones en la elevación y un subsecuente adelgazamiento corneal \cite{namba}.
\end{itemize}

En muchos países, incluyendo México, la detección del queratocono se ve impedida por la falta de especialistas y recursos necesarios para la enfermedad. Este proyecto busca simplificar el proceso de diagnóstico, permitiendo un acceso más amplio a estudios especializados y facilitando el trabajo de los profesionales capacitados.

\section{Desarrollo}

En esta sección se presenta y explica el proceso que se llevó a cabo para el desarrollo del proyecto en sus diferentes etapas.

\subsection{Datos utilizados}

El dataset utilizado fue obtenido de Kaggle \cite{bakir}. Se trata de un dataset compuesto de 3162 muestras recolectadas de una maquina TOMEY Casia SS-1000, un tomógrafo de coherencia óptica, utilizado para el diagnóstico de problemas en la córnea.

Como ya se comentó, son alrededor de 3200 muestras, que están mas enfocados para el estudio con especialistas. No son como tal las tomografías, solo los datos recolectados.

\subsection{Análisis exploratorio}

Para el análisis exploratorio podemos realizar varios procesos para observar la estructura de los datos, podemos ver las distintas distribuciones de los datos o simplemente entenderlos y tener una idea de para poder realizar nuestros modelos.

Contamos con 3162 filas y 448 columnas. Entre las columnas se pueden hallar algunas variables de importancia en la queratometría que incluyen parámetros biométricos, medidas de curvatura, elevación, espesor, entre otros.

Se realizaron diversas gráficas para poder visualizar de mejor manera la estructura que tienen algunas columnas. En general, son unos datos bastante limpios y completos, no se contaban con valores nulos y se tiene una cierta coherencia. Realmente todos estos datos tienen alguna función, y lo ideal sería poder revisar de manera exhaustiva el manual de la máquina o tener la ayuda de un especialista para poder darle aún más sentido e interpretación a todos estos datos.

\subsection{Preprocesamiento}

En la etapa de preprocesamiento se realizaron diversos procesos para preparar los datos.

Como ya se mencionó, no se contaban con valores nulos dentro del dataset. Después de eso, se obtuvieron dos columnas con valores tipo ``objeto'', por lo tanto se pueden descartar.

Un paso importante es la eliminación de valores con una baja varianza, con la ayuda de una función de filtrado \textit{VarianceThreshold} se eliminaron variables constantes y cuasiconstantes. Además, se hicieron diversas pruebas ajustando el \texttt{threshold} y así obtener mas o menos características, revisando en todo momento el como reaccionaba el modelo predictivo final.

Los datos no requieren de una normalización, ya que se utilizará un modelo que no lo necesita. En una sección siguiente se aplica un PCA (Análisis de Componentes Principales), el cual sí requiere una escalamiento estándar a las características numéricas.

Después de la ``limpieza'', se codificaron las etiquetas contenidas en un segundo archivo (.csv) con un \texttt{LabelEncoder}, las cuales contienen 4 valores (del 0 al 3) e indican la etapa del queratocono presente en cada muestra.

Finalmente, se divide el conjunto de datos en una sección de entrenamiento y otra de prueba con una función \texttt{train\_test\_split} en una relación 80 / 20.


\subsection{Reducción de dimensionalidad}

Se evaluaron dos métodos métodos para reducir la dimensionalidad del dataset, y comprobar su efectividad utilizando el modelo predictivo.

\begin{enumerate}[itemsep=-2pt]
    \item  \textbf{PCA}: A partir de las componentes principales, se identifican aquellas que mejor explican la varianza de los datos.
    \item  \textbf{SelectKBest}: Con el uso de \texttt{f\_classif} se seleccionaron las características más relevantes estadísticamente con respecto a la variable o características objetivo.
\end{enumerate}

\subsection{Selección del Modelo}

Para seleccionar el modelo a utilizar, se realizaron pruebas con 8 modelos distintos incluidos en la librería de Scikit-Learn. Todos los modelos se encuentran en el repositorio del proyecto. Se evaluaron con su precisión obtenida, su exactitud y una matriz de confusión para las predicciones con el conjunto de datos de prueba.

\begin{itemize}[itemsep=-2pt]
    \item \textbf{Random Forest}. Compuesto de árboles de decisión, cada árbol vota y el resultado final es la clase más votada (clasificación), tiene robustez ante ruido y alta dimensionalidad. \cite{biau}
    \item \textbf{Logistic Regression}. Modelo lineal para clasificación binaria/multiclase, utiliza una función sigmoide para estimar probabilidades (0 a 1), pero es muy sensible a correlaciones entre características. \cite{cramer}
    \item \textbf{k-Nearest Neighbors}. Clasifica un punto según la mayoría de clases de sus $k$ vecinos más cercanos, es costoso computacionalmente en datasets grandes. \cite{cunningham}
    \item \textbf{Support Vector Machine}. Encuentra un hiperplano óptimo que maximiza el margen entre clases, usa kernels (ej. RBF) para separar datos no lineales; es efectivo en espacios de alta dimensión pero poco escalable. \cite{novakovic}
    \item \textbf{Decision Tree}. Modelo que divide datos mediante reglas if-else (nodos), suele ser propenso al overfitting; es útil para visualizar decisiones. Es la base del Random Forest y el Gradient Boosting. \cite{mienye}
    \item \textbf{Naive Bayes}. Clasificador basado en el teorema de Bayes, asumiendo independencia entre características. Es rápido y eficiente con datos de alta dimensión, pero pierde precisión si hay correlaciones fuertes. \cite{vikramkumar}
    \item \textbf{Gradient Boosting}. Técnica que construye árboles secuencialmente, corrigiendo errores del anterior (el llamado boosting). Mayor precisión que un Random Forest pero más propenso al overfitting. \cite{friedman}
    \item \textbf{Neural Network}. Modelo no lineal inspirado en neuronas biológicas, con capas ocultas que aprenden patrones. Requiere muchos datos y ajuste de hiperparámetros. Suele ser bastante bastante demandante computacionalmente en conjuntos de datos grandes. \cite{zhang}
\end{itemize}

El modelo final utilizado fue un \textbf{Random Forest Classifier}, por su capacidad de manejar datos de alta dimensión y su robustez ante el overfitting, además de su simplicidad y bajo tiempo de ejecución. Se busca mejorar el rendimiento todo lo posible con un ajuste de los hiperparámetros.

\subsection{Ajuste de hiperparámetros}

Para mejorar el modelo base, se aplicaron dos métodos para poder encontrar los hiperparámetros que mejores resultados nos proporcionaran.

\begin{itemize}[itemsep=-2pt]
    \item \textbf{GridSearch}.\\ Se trata de un método que busca la mejor combinación de parámetros entre todas las posibilidades dentro de los valores que se le indican.
    \item \textbf{RandomizedSearch}.\\ Este método busca combinaciones de parámetros de manera aleatoria durante varias iteraciones, dándonos como resultado la mejor que se haya encontrado.
\end{itemize}

Este ajuste de hiperparámetros puede ser incluso más exhaustivo que el que se aplicó en este proyecto, pero debido a su costo computacional, es bastante lento el proceso. Ambos procesos se incluyen en el repositorio del proyecto.

\subsection{Reducción de dimensionalidad}

La reducción de dimensionalidad es una técnica que consiste en transformar datos con muchas variables (dimensiones) en una representación más compacta, conservando la información más relevante. En nuestro caso particular contamos con un dataset de 450 variables, lo cual puede ser redundante, por lo tanto no se pierde nada intentándolo.

Como resultado, no obtuvimos una mejoría al realizar esta reducción. Se utilizaron dos métodos.

\subsubsection{\textbf{PCA}}

El primer método para la reducción de la dimensionalidad es el \texttt{PCA} o Ánalisis de Componentes Principales. Se trata de una es una técnica que transforma un conjunto de variables correlacionadas en un nuevo conjunto de variables no correlacionadas las cuales llamaremos componentes principales. Estas nuevas componentes capturan la mayor variabilidad de los datos con número menor de dimenisiones.

Nuestro modelo presenta un rendimiento bastante aceptable, pero sin mejoría significativa. La matriz de confusión obtenida a partir de nuestro modelo base (RandomForest) se presenta en la figura \ref{fig:MatrizPCA} a continuación.

\begin{figure}[hbt!]

    \caption{Matriz de confusión del RandomForest base haciendo uso del PCA.}
    \label{fig:MatrizPCA}
\end{figure}

\subsubsection{\textbf{Mejores Variables}}

El segundo método para la reducción de dimensionalidad se trata de una selección de las mejores variables. \texttt{SelectKBest} es un método que escoge las $k$ mejores variables según una métrica estadística (como correlación con la o las variables objetivo).

\section{Análisis y Discusión}

\begin{itemize}
    \item Es posible detectar queratocono con alta precisión utilizando técnicas de aprendizaje automático.
    \item El modelo Random Forest es una opción viable y eficiente para la clasificación multicategoría.
    \item Se necesita más información para refinar la detección de las etapas más graves.
    \item Este tipo de herramienta puede ser integrada en entornos clínicos para asistir a especialistas.
\end{itemize}

\section{Pruebas de diversos modelos}
\label{app:Modelos}
